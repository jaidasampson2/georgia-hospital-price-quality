# Interactive Dashboard

Live dashboard: https://public.tableau.com/views/GeorgiaHospitalPriceQualityExplorer/Dashboard1

Built in Tableau Public, connecting to the price and quality exports in
this folder (`prices_for_tableau.csv`, `quality_for_tableau.csv`).
Regenerate these exports by running the queries in
`sql/export_prices_for_tableau.sql` and `sql/export_quality_for_tableau.sql`
against `data/hospital_prices.db`.
