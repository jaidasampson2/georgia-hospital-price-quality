# Data Directory

This project uses publicly available hospital price-transparency files and CMS hospital-quality data.

## Folders

- `raw/`: Original downloaded files. These files are not uploaded to GitHub.
- `processed/`: Cleaned and standardized datasets. Large files are not uploaded to GitHub.
- `sample/`: Small sample datasets used to demonstrate the pipeline.

## Data Privacy

This project uses public hospital-level information only. It does not contain patient-level records or protected health information.
